# Find ved at fravælge

Åbn `index.html` i denne mappe for den selvstændige eReolen GO!-funktion.

Forløb: introduktion → fravælg tre bøger → fravælg tre nye bøger → vælg til/fra efter sidetal → se fælles temaer og vælg bog eller få flere beslægtede forslag. Alle bogdata, sidetal og temaer er illustrative; forsiderne kommer fra `../design-system-reference/assets/`.
